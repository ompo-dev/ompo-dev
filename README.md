## 🧑‍💻 About me

I'm a **Software Engineer focused on modern web applications**, with strong experience in Front-end and growing work across Backend, infrastructure and software architecture.

My main ecosystem is **TypeScript**, building products with **React, Next.js, Node.js and PostgreSQL** — from interface and state management to APIs, authentication, data modeling and deployment.

I enjoy working on problems involving:

* scalable application architecture
* complex interfaces and design systems
* offline-first applications
* observability and metrics
* API design and integrations
* distributed and event-driven systems
* performance and developer experience
* turning product ideas into working software

I care less about simply making something *work* and more about understanding **why it works, how it fails and how it can scale**.

`Next.js` `React` `TypeScript` `Bun` `Elysia` `Prisma` `PostgreSQL`

* Offline-first architecture with IndexedDB
* local command queue and background synchronization
* idempotency and retry strategies
* authentication and user management
* workout and nutrition systems
* gamification with XP, streaks and achievements
* gym management and reporting

### 📊 Metrio

**Observability and business metrics platform focused on transforming events into useful information.**

`Next.js` `TypeScript` `Node.js` `PostgreSQL` `Webhooks`

* webhook pipelines
* dynamic metrics
* dashboards and aggregations

* experimentation with observability architecture
